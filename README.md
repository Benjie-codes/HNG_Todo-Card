# Todo Card Web App

The Todo-Card web app is a simple application that allows users to manage their daily tasks. Users can enter a task along with a deadline; once each task has been created, the user can proceed to edit, delete, or mark it as completed.

## Features

- **Create Tasks:** Add new tasks and set their deadlines.
- **Edit Tasks:** Update existing tasks (added an edit feature to the card from the simple UI for Stage 1 HNG Internship).
- **Delete Tasks:** Remove tasks that are no longer needed.
- **Complete Tasks:** Check off tasks when they are done.

## Design Philosophy

The minimalist design still remains through this stage because the goal is to learn how to work and establish a good design system. 

## Limitations

Currently, there are no visible limitations for this project as the task is simply to build a todo card web app. However, please note that **users with visual impairments will have difficulty using the application** at this stage as it was not built with accessibility in mind.
