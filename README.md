Added an Todo task edit feature to the card from the simple UI in Stage 0. 
The minimalist design still remains through this stage because i want to learn how to work ad establish and Good design system. 
Currently there are no visible limitations for this project as the task is to build a todo card web app.
The Todo-Card web app is a simple application that requires the user to enter task and a deadline; Once each task has been created, the user can proceed to edit, delete or check if the task has been completed. 
Users with Vision impedement wil have a difficulty using the application.
